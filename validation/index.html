Validation record

The calculations in the Laser Safety Assessment, run against values published by independent sources. This page runs the tool's own calculation code each time it opens, so it always shows what the current version produces.

What was checked

  • Hazard distances (direct beam, lens on laser, diffuse reflection): the 18 values in the OSHA Technical Manual's nominal hazard zone table, using the MPE values OSHA used.
  • Maximum permissible exposure, as the tool looks it up from ANSI Z136.1-2022: against the OSHA Technical Manual's MPE table and the University of Nebraska-Lincoln calculation guide.
  • Eyewear optical density, from the looked-up MPE through to the OD: against the OSHA Technical Manual's eyewear table and worked example, and the Nebraska guide.

A case agrees when the tool is within 2% of the published value (3% for the diffuse distances and the MPE values, which are published to two digits), or, for optical density, within 0.05 before rounding up.

What is not covered by this record

  • Automatic MPE from 700 to 1400 nm and for visible light over 10 seconds. The tool does not calculate these yet and asks for the MPE to be entered. The hazard distance formulas were checked at 1064 nm with the MPE OSHA gives.
  • Fiber and mirror-like (specular) reflection distances, and skin MPE: no independent published values were found to check them against.
  • Repetitive pulses: one published example was checked.

Sources

  • OSHA Technical Manual, Section III, Chapter 6, Laser Hazards: Tables III:6-6, III:6-7 and III:6-8 and Equation III:6-1.
  • University of Nebraska-Lincoln Environmental Health and Safety, Laser Safety Calculation Guide (7/24).
